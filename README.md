### Project Description
An interactive web-based game where the user defends the city by shooting webs using real-life hand gestures via their webcam!

### The Problem (that doesn't exist)
Not everyone is bitten by a radioactive spider, but everyone wants to shoot webs at bad guys. Current technology completely fails to address this critical societal need.

### The Solution (that nobody asked for)
Turning your webcam into a fully functional web-shooter using AI hand-tracking. By performing the iconic Spider-Man gesture (squeezing your middle fingers to your palm), you can shoot virtual webs at enemies on your screen. It features magnetic aim-assist, dynamic sound effects, and a combo multiplier.
